# HDM 1 judging board

Static, password-protected results board for the Evaluation Hackathon (HDM 1).
All data in this repository is AES-256-GCM encrypted; the page decrypts them
in the browser after the password is entered. Scores in the "AI /100" column are AI-generated
against the official rubric; the sandbox results come from offline Docker runs.

Host with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
